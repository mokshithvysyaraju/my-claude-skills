# my-claude-skills

A personal collection of [Claude Agent Skills](https://github.com/anthropics/skills) I've built for my own use — reusable, structured instructions that guide Claude through specific tasks and workflows.

## What's in here

Each skill lives in its own folder with a `SKILL.md` file (instructions + metadata) and, where needed, extra reference files or scripts.

| Skill | What it does |
|---|---|
| [`git-github-mentor`](https://github.com/mokshithvysyaraju/my-claude-skills) | A structured, hands-on mentor that teaches Git and GitHub from scratch — version control basics, branching, remotes, pull requests, and how to recover from mistakes. |

More will be added here as I build them.

## How to use these skills

1. Download or clone this repo.
2. Upload the relevant skill folder (or its packaged `.skill` file) to Claude.
3. Ask Claude about the topic the skill covers — it will trigger automatically based on the skill's description.

## Why I'm doing this

I'm learning software development, starting with version control as the foundation. This repo is both a practical tool (a place to store and version my own Claude skills) and practice for using Git and GitHub in a real, ongoing way.
